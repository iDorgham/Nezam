## What is v0.3.5?

**NEZAM v0.3.5** is the production-ready polish release of our acceleration system.

It replaces v3.2 with three key improvements:
1. **Clearer versioning** (v0.x = development/refinement phase)
2. **Three-tier rollout** (core → enhanced → polish, not all-at-once)
3. **Production polish** (all docs, monitoring, and runbooks complete)

## FAQ

**Q: Do I have to use `/plan`?**  
A: No. Use it for new features to get context-injected specs. For quick fixes, use `/quick` (bypasses planning).

**Q: Can I override automation?**  
A: Yes. Every step has a `--manual` flag. Or `/silent pause` to disable automation for the session.

**Q: What if deployment fails?**  
A: Rollback is 1-click. All previous versions are tagged and available. MTTR < 15min (monitored).

**Q: How fast does this really work?**  
A: Typical feature (web app): 12h (vs 24h before). CLI: 4.75h (vs 12h). Website: 8h (vs 28h).

**Q: What about my existing code?**  
A: Nothing changes. New commands are opt-in. Existing workflows still work.
