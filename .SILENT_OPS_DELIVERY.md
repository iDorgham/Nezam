## Key Features

### **Silent Polling**
Gates run in background. No spam. Only output on state change:
```
[14:32] ✅ Lint passed
[14:45] ✅ Test passed
[15:03] ✅ Security passed
[15:04] 🟡 Waiting for your approval
        → PR: https://github.com/.../pull/82
```

### **Task Auto-Linking**
Extract task ID from commit message → auto-link PR → auto-update MASTER_TASKS.md:
```
/silent commit "T-V32-1-001: pnpm ai:sync"
```
→ Automatically:
- Creates PR with title: `feat(v3.2-P1): pnpm ai:sync [T-V32-1-001]`
- Links task in PR body
- Updates MASTER_TASKS.md: `status: ⏳ In Review`
- On merge: `status: ✅ Done`

### **Tier-Aware Automation**
Same commands, different behavior:
- **LITE:** Auto-merge when gates pass
- **STANDARD:** Merge after you approve
- **ENTERPRISE:** Merge after multiple approvals + audit trail

### **Full Audit Trail**
All operations logged:
```
.nezam/logs/silent-ops.log
.nezam/logs/deployments.log
.nezam/logs/releases.log
```

### **Slack Notifications**
Auto-post to #dev and #deploys:
```
✅ T-V32-1-001 committed → PR #82
🟡 T-V32-1-001 waiting for approval
✅ T-V32-1-001 merged → v3.2.0-alpha.1
🚀 Deployed to staging → https://...
```
