# NEZAM — Versioning Strategy

## Current Version: 0.1.0-alpha

## Versioning Rules
- **Semantic Versioning (SemVer):** `MAJOR.MINOR.PATCH`
- **Major:** Architectural shifts or breaking pipeline changes.
- **Minor:** New features, new agents, or updated skills.
- **Patch:** Bug fixes, script corrections, or documentation updates.
