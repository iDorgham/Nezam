## Risks & Mitigation

| Risk | Mitigation |
|------|-----------|
| **Figma MCP auth fails** | Provision early; test immediately in phase 1 |
| **CI pipeline too complex** | Test on feature branch before merging; iterate on gate logic |
| **Security audit finds major issues** | Schedule remediation in parallel; don't block release on high-effort fixes |
| **Team bandwidth tight** | Stagger phases; allow partial parallel work; hire contractor if needed |
| **Scope creep** | Freeze scope after Jun 7; defer to v3.3 |
| **Design system gaps** | Audit early in phase 4.2; fix before unlock gate |
