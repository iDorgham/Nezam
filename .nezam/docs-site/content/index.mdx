# Specification-driven development for AI-native teams

NEZAM governs Cursor, Claude, Codex, and more with one pipeline:
**plan → lock design → scaffold → develop**, with hardlocks that block unsafe work.

> *Specification-driven delivery for builders who think in systems.*

## Get started

Run `/START all` in Cursor — or [browse commands](/commands/plan) and open Design Hub locally.

## Value pillars

### Governed pipeline
PRD, plans, specs, and gates before code. No more agents skipping planning to jump to implementation.

### Design Hub
Approve architecture and wireframes; export `wireframes_locked.json` as the source of truth for development.

### Multi-client sync
Edit `.cursor/` once; `pnpm ai:sync` updates every mirror — Claude, Gemini, Codex, OpenCode.

## How it works

1. **Define** — Lock a PRD, choose a design profile.
2. **Plan** — SEO, IA, content, architecture, wireframes, scaffold, tasks.
3. **Lock design** — Export `wireframes_locked.json`.
4. **Develop** — Build phase-by-phase with hardlocks between phases.
