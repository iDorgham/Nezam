# NEZAM — Getting Started with GitHub Copilot

> **Tier 1 tool.** Copilot reads `AGENTS.md` at repo root. Works in VS Code, JetBrains, Neovim, and via the CLI.

## How NEZAM works with Copilot

GitHub Copilot reads `AGENTS.md` at repo root as workspace context. This file contains the full NEZAM agent index, command routing, and SDD pipeline rules. Copilot Chat uses it to understand the project structure and respond to NEZAM slash commands.

## First-time setup

```bash
# 1. Clone the repo and install dependencies
git clone <repo-url>
cd your-project
pnpm install

# 2. Install the git pre-commit hook
bash scripts/hooks/setup-hooks.sh

# 3. Sync mirrors (ensures AGENTS.md is current)
pnpm ai:sync
```

## VS Code setup (recommended)

Install **GitHub Copilot** and **GitHub Copilot Chat** extensions, then open the project. The `.vscode/settings.json` generated by `pnpm ai:sync` configures Copilot to read `AGENTS.md` and `VSCODE.md` as workspace context automatically.

## Copilot Chat commands

In the Copilot Chat panel (`Ctrl+Shift+I` / `Cmd+Shift+I`):

```
/start all
```

All NEZAM slash commands work in Copilot Chat. If a command doesn't trigger as a slash command, type it as natural language:

```
Run the NEZAM start all onboarding flow
```

## Copilot CLI

```bash
# Install Copilot CLI extension
gh extension install github/gh-copilot

# Use NEZAM commands
gh copilot suggest "/start all"
gh copilot suggest "/guide status"
gh copilot suggest "/plan arch"
gh copilot suggest "/develop start"
```

## Copilot Workspace

For Copilot Workspace (GitHub.com), NEZAM context is available via `AGENTS.md` in the repository root. Open a Copilot Workspace session on any issue or PR and the agent will read the NEZAM governance rules automatically.

## Key commands

| Command | What it does |
|---------|-------------|
| `/start all` | Full onboarding — start here |
| `/guide status` | See where you are and what's next |
| `/guide next` | Get the single most important next step |
| `/plan seo` | Run the SEO research phase |
| `/plan arch` | Run the architecture phase |
| `/develop start` | Begin development (requires planning complete) |
| `/check output` | Score the last output |
| `/check gate` | Verify all gate prerequisites |
| `/fix` | Fix any issue (never hardlocked) |
| `/scan all` | Run full project health scan |

## Keeping in sync

```bash
pnpm ai:sync   # sync .cursor/ → AGENTS.md and all other mirrors
pnpm ai:check  # verify no drift
```

## Troubleshooting

- **Copilot not reading NEZAM context** → confirm `AGENTS.md` exists at repo root (run `pnpm ai:sync`)
- **Gate fails unexpectedly** → run `/check repair` to validate state files
- **Design not applying** → confirm `DESIGN.md` exists at repo root
