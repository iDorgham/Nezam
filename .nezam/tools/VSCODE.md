# NEZAM — Getting Started with VS Code

> **Tier 2 tool.** VS Code reads `VSCODE.md` at repo root and `.vscode/nezam/` for workspace context. Works with GitHub Copilot, Continue.dev, and other AI extensions.

## How NEZAM works in VS Code

VS Code + GitHub Copilot reads `VSCODE.md` as workspace context for all AI interactions. NEZAM mirrors all commands, agents, skills, and rules from `.cursor/` into `.vscode/nezam/` so the full SDD pipeline is available via Copilot Chat.

## First-time setup

```bash
# 1. Clone the repo and install dependencies
git clone <repo-url>
cd your-project
pnpm install

# 2. Install the git pre-commit hook
bash scripts/hooks/setup-hooks.sh

# 3. Sync mirrors (generates .vscode/nezam/ from .cursor/)
pnpm ai:sync

# 4. Open in VS Code
code .
```

## Recommended extensions

Install these for the best NEZAM experience in VS Code:

| Extension | Purpose |
|-----------|---------|
| **GitHub Copilot** | Primary AI assistant — reads `VSCODE.md` |
| **GitHub Copilot Chat** | Chat interface for slash commands |
| **Continue.dev** | Alternative AI chat with `.continue/` rules support |

## Copilot Chat setup

NEZAM ships `.vscode/settings.json` that tells Copilot to read `VSCODE.md` as workspace context:

```json
{
  "github.copilot.chat.codeGeneration.instructions": [
    { "file": "VSCODE.md" }
  ],
  "github.copilot.chat.reviewSelection.instructions": [
    { "file": "VSCODE.md" }
  ]
}
```

This is auto-generated by `pnpm ai:sync` — no manual setup needed.

## Starting a new project

In the Copilot Chat panel (`Ctrl+Shift+I` / `Cmd+Shift+I`):

```
/start all
```

## Key commands

| Command | What it does |
|---------|-------------|
| `/start all` | Full onboarding — start here |
| `/guide status` | See where you are and what's next |
| `/guide next` | Get the single most important next step |
| `/plan seo` | Run the SEO research phase |
| `/plan arch` | Run the architecture phase |
| `/develop start` | Begin development (requires planning complete) |
| `/check output` | Score the last output |
| `/check gate` | Verify all gate prerequisites |
| `/fix` | Fix any issue (never hardlocked) |
| `/scan all` | Run full project health scan |

## GitHub Copilot CLI

If you use Copilot CLI (`gh copilot`), NEZAM commands work via `AGENTS.md`:

```bash
gh copilot suggest "/start all"
gh copilot suggest "/guide status"
gh copilot suggest "/plan arch"
```

## Design profiles

```
/start design
```

Browse 150+ curated design profiles in `.nezam/design/`. Each profile sets colors, typography, spacing, and component style.

## Keeping in sync

```bash
pnpm ai:sync   # sync .cursor/ → .vscode/nezam/ and all other mirrors
pnpm ai:check  # verify no drift
```

## Troubleshooting

- **Copilot not reading NEZAM context** → confirm `VSCODE.md` exists at repo root and `.vscode/settings.json` has the instructions block
- **Gate fails unexpectedly** → run `/check repair` to validate state files
- **Design not applying** → confirm `DESIGN.md` exists at repo root
- **PRD not found** → check `.nezam/workspace/prd/PRD.md` exists and has content
