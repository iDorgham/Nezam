# DESIGN

## Visual Summary
Restrained color strategy: tinted neutrals with a single accent (≤10%). Functional/interface typography. Subtle motion (micro-interactions, gentle easing). Accessibility target: WCAG AA.

## Color Strategy
- Strategy: Restrained — tinted neutrals across surfaces; one brand accent used sparingly (buttons, primary CTAs).
- Accent suggestion (example): brand-accent: #2563eb (adjust to OKLCH when refining).
- Neutral tints: light and dark neutrals should be slightly tinted toward the brand hue to avoid pure #000/#fff.

## Typography
- Direction: Functional / Interface.
- Headings: Inter / System UI variable with strong weight scale (600–800). Maintain ≥1.25 scale step between heading levels.
- Body: Inter / System font at 16px base; cap line length 65–75ch.

## Spacing & Layout
- Use a 4px base spacing scale with tokens: 4,8,12,16,24,32,48.
- Keep rhythm by varying container padding between contexts; avoid identical card grids.

## Components
- Buttons: primary (accent, filled), secondary (tinted neutral), ghost (outline/tint). Avoid side-stripe borders.
- Forms: inline validation, avoid modal-first patterns.
- Cards: use only when semantic grouping is required; avoid nested cards.

## Motion
- Subtle micro-interactions: fade/translate with ease-out-quad/quart. No layout-animating CSS properties.
- Respect reduced-motion preference.

## Accessibility
- Target: WCAG AA. Contrast for text and UI elements must meet AA ratios; provide reduced-motion and keyboard focus states.

- Visual reference provided: https://www.magnific.com/app
