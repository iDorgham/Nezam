## 🚀 How to Execute

### Option A: Run a Single Phase

```bash
# Phase 1: Foundation (8 hours)
claude-code --task "NEZAM v3.2 Phase 1: Foundation Hardening"

# Phase 2: CI/CD (20 hours)
claude-code --task "NEZAM v3.2 Phase 2: CI/CD Pipeline Full Validation"

# Phase 3: Security (10 hours)
claude-code --task "NEZAM v3.2 Phase 3: Security & Compliance Automation"

# Phase 4: Design (16 hours)
claude-code --task "NEZAM v3.2 Phase 4: Wireframe Server Integration"

# Phase 5: Content (14 hours)
claude-code --task "NEZAM v3.2 Phase 5: Content Ops & Analytics"

# Phase 6: Integration (14 hours)
claude-code --task "NEZAM v3.2 Phase 6: Integration, Documentation & Release"
```

### Option B: Run Phases in Parallel

```bash
# Run phases 3, 4, 5 in parallel (they don't depend on each other)
claude-code --task "NEZAM v3.2 Phase 3: Security & Compliance Automation" &
claude-code --task "NEZAM v3.2 Phase 4: Wireframe Server Integration" &
claude-code --task "NEZAM v3.2 Phase 5: Content Ops & Analytics" &
wait
```

### Option C: Full Handoff Document

All phases are fully specified in `.nezam/core/prompts/v3.2-claude-code-handoff.md`

## 🔧 Troubleshooting

**Agent times out during execution:**
- Increase timeout: `claude-code --task "..." --timeout 3600`
- Or break into smaller phases

**Agent can't find files:**
- Ensure paths are absolute (not relative)
- Run from project root: `cd /path/to/NEZAM`
- Check `.nezam/core/` exists

**Phase depends on previous phase completion:**
- Don't run Phase 2 until Phase 1 is done
- Phases 3, 4, 5 can run in parallel (no dependencies)
- Phase 6 needs all others complete

**Need to resume mid-phase:**
- Claude Code agents are stateless
- Re-run the full phase task
- Agent will skip completed items (if documented in status file)
